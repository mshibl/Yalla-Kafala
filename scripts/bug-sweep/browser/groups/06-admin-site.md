**Who:** the admin. Open `{{BASE_URL}}/api/council/login` first. The admin area is English.

**Screens:**

- Board members: the list (published and unpublished, per country), edit a member's name, role or order, publish and unpublish, delete one (with the confirmation); check each change on the public `/en/who-we-are` page and its Arabic twin. Adding a member needs a picture upload, which is not covered: open the form, check its validation, leave
- Carousel: the list of pictures, edit a caption in both languages; check the Home page carousel shows it. Don't upload
- Resources: the list, edit a resource's title, text and link; check `/en/resources` and the resource page. Don't upload

**Look hard at:** a change that doesn't reach the public page, an unpublished member that still shows, forms that accept an empty required field, lost edits when you press Back, the tables and forms at 360 px, missing confirmations before deleting.
